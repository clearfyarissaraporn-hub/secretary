# เลขาส่วนตัว · แอป Android

แอปเดิมทุกอย่าง + **แจ้งเตือนจากในเครื่อง** (นัด · เวรพรุ่งนี้ · วันหยุดบริษัท · รูทีนที่มีเวลา)
เด้งตรงเวลาแม้ปิดแอปหรือไม่มีเน็ต **ไม่ต้องตั้งเซิร์ฟเวอร์**

GitHub สร้างไฟล์แอป (.apk) ให้อัตโนมัติ ไม่ต้องติดตั้งโปรแกรมใด ๆ

---

## ครั้งแรก (ทำครั้งเดียว ~15 นาที)

### 1) สร้าง repository ใหม่
GitHub › **+** › **New repository** › ชื่อ `secretary-android` › เลือก **Private** › **Create repository**

### 2) อัปไฟล์ (แนะนำทำบนคอม)
แตกไฟล์ zip แล้วลากไฟล์และโฟลเดอร์ทั้งหมดขึ้นไป (ต้องมีโฟลเดอร์ `.github` `www` `assets` `scripts` `signing` ครบ) › **Commit changes**

> โฟลเดอร์ `.github` เป็นโฟลเดอร์ซ่อน ถ้ามองไม่เห็นในคอม ให้เปิด “แสดงไฟล์ที่ซ่อน” ก่อน
> หรือสร้างเองบนเว็บ: **Add file › Create new file** ตั้งชื่อ `.github/workflows/build-android.yml` แล้ววางเนื้อหาจากไฟล์เดียวกันใน zip

### 3) รอ GitHub สร้างแอป
แท็บ **Actions** › รอ “Build Android APK” ประมาณ 8–12 นาที จนขึ้น ✅ สีเขียว
(ถ้าขึ้น ❌ สีแดง แตะเข้าไป › แคปหน้าจอบรรทัดสีแดงส่งมาให้แก้)

### 4) ติดตั้งบนมือถือ
บนมือถือ เปิด repository › **Releases** (ด้านขวา หรือเลื่อนลงล่าง) › แตะไฟล์ `secretary-vN.apk` › ดาวน์โหลด › แตะเพื่อติดตั้ง
- มือถือถามเรื่อง “ติดตั้งแอปจากแหล่งที่ไม่รู้จัก” › อนุญาตให้เบราว์เซอร์นั้น
- ตั้งแต่ 30 ก.ย. 2569 ประเทศไทยบังคับยืนยันตัวตนนักพัฒนาสำหรับแอปที่ติดตั้งนอก Play Store ถ้ามือถือขึ้นว่าติดตั้งไม่ได้ ให้ใช้ขั้นตอน **ติดตั้งแบบขั้นสูง (advanced flow)** ตามที่มือถือแนะนำ หรือติดตั้งผ่าน Play Console แบบทดสอบภายใน (ดูด้านล่าง)

### 5) ย้ายข้อมูลเข้าแอป Android
แอปนี้เก็บข้อมูลแยกจากแอปเว็บเดิม
แอปเว็บเดิม › ตั้งค่า › **ดาวน์โหลดไฟล์สำรอง** › แอป Android › ตั้งค่า › **นำเข้าไฟล์สำรอง**

### 6) เปิดแจ้งเตือน
แอป Android › **ตั้งค่า › การเตือนนัด › เปิดแจ้งเตือน** › อนุญาต
- ถ้าขึ้น “ยังไม่อนุญาตนาฬิกาปลุกและการเตือน” › กด **เปิดสิทธิ์** › เปิดสวิตช์ให้แอปนี้
- กด **ทดสอบเด้ง (10 วินาที)** › ปิดแอป › ต้องมีแจ้งเตือนเด้ง
- ตั้งค่ามือถือ › แอป › เลขาส่วนตัว › แบตเตอรี่ › **ไม่จำกัด** (กันมือถือปิดแจ้งเตือนเพื่อประหยัดแบต)

## อัปเดตแอปครั้งต่อไป
แทนที่ `www/index.html` ด้วยไฟล์เวอร์ชันใหม่ › Commit › รอ Actions ✅ › ดาวน์โหลด apk ใหม่จาก Releases › ติดตั้งทับ (**ข้อมูลไม่หาย** เพราะใช้กุญแจเซ็นแอปเดิมทุกครั้งจากโฟลเดอร์ `signing`)

> ห้ามลบหรือเปลี่ยนไฟล์ `signing/debug.keystore` ไม่งั้นต้องถอนแอปเก่าก่อนติดตั้ง (ข้อมูลในแอปหาย ต้องนำเข้าไฟล์สำรองใหม่)
> กุญแจนี้ใช้สำหรับทดสอบ เก็บ repository เป็น **Private** · ก่อนขายจริงจะเปลี่ยนเป็นกุญแจสำหรับ Play Store

## ถ้าจะขายบน Play Store (ภายหลัง)
- สมัคร Google Play Console (ค่าสมัครจ่ายครั้งเดียว) และยืนยันตัวตน
- ทดสอบภายใน (internal testing) ติดตั้งผ่าน Play ได้ทันทีโดยไม่ติดเรื่องติดตั้งนอก Store
- บัญชีส่วนตัวที่สร้างใหม่ต้องทดสอบแบบปิดกับผู้ทดสอบอย่างน้อย 12 คน ต่อเนื่อง 14 วัน ก่อนเปิดขายจริง

## มีอะไรในโฟลเดอร์นี้
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `www/index.html` | ตัวแอป (ไฟล์เดียวกับเวอร์ชัน GitHub) |
| `capacitor.config.json` | ชื่อแอปและรหัสแอป |
| `package.json` | ส่วนประกอบแอป Android (Capacitor 8 + แจ้งเตือน + แชร์ไฟล์) |
| `.github/workflows/build-android.yml` | สั่ง GitHub สร้าง apk อัตโนมัติ |
| `scripts/patch_android.py` | เพิ่มสิทธิ์แจ้งเตือน/นาฬิกาปลุก |
| `assets/` | ไอคอนและหน้าเปิดแอป |
| `signing/debug.keystore` | กุญแจเซ็นแอป (ให้อัปเดตทับได้) |

## ขึ้น GitHub Pages ทีละขั้น

ทำบนคอมพิวเตอร์จะง่ายที่สุด (บนมือถือก็ทำได้ผ่าน Chrome แบบ “เวอร์ชันเดสก์ท็อป”)

1. **สมัครบัญชี** ที่ [github.com](https://github.com) (ฟรี)
2. **สร้าง repository**: กด **+** มุมขวาบน › **New repository**
   - Repository name: `secretary` (ชื่อนี้จะเป็นท้ายลิงก์เว็บไซต์)
   - เลือก **Public** (GitHub Pages แบบฟรีต้องเป็น Public)
   - กด **Create repository**
3. **อัปโหลดไฟล์**: ในหน้า repository กด **uploading an existing file** (หรือ **Add file › Upload files**)
   - แตกไฟล์ zip ก่อน แล้วเลือก**ไฟล์ทั้ง 8 ไฟล์**อัปโหลดพร้อมกัน (ไม่มีโฟลเดอร์ย่อย อัปจากมือถือได้)
   - กด **Commit changes**
4. **เปิด GitHub Pages**: ไปที่ **Settings › Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** และโฟลเดอร์ **/ (root)** › กด **Save**
5. **รอ 1–3 นาที** แล้วรีเฟรชหน้า Settings › Pages จะขึ้นลิงก์แบบนี้
   `https://ชื่อผู้ใช้.github.io/secretary/`
6. เปิดลิงก์นั้น ใช้งานได้ทันที

> ⚠️ **ห้ามอัปไฟล์สำรอง (`secretary-backup-….json`) หรือไฟล์ Excel/PDF ที่ดาวน์โหลดจากแอปขึ้น GitHub** เพราะ repository เป็น Public ทุกคนเปิดดูได้

ข้อมูลของแต่ละลิงก์แยกกัน ต้องย้ายเองครั้งเดียว

1. เปิดแอปบน **claude.ai** › **ตั้งค่า › สำรองข้อมูล › ดาวน์โหลดไฟล์สำรอง**
2. เปิดแอปบน **GitHub** › **ตั้งค่า › สำรองข้อมูล › นำเข้าไฟล์สำรอง** › เลือกไฟล์ › ยืนยัน

ย้ายระหว่างมือถือกับคอมพิวเตอร์ก็ใช้วิธีเดียวกัน

## อัปเดตแอปเวอร์ชันใหม่

1. อัปโหลดไฟล์ทั้งหมดจาก zip ใหม่ทับของเดิมบน GitHub (**ต้องมี `version.json` ด้วย**) › Commit changes › รอ 1–3 นาที
2. เปิดแอป จะมีการ์ด **“มีเวอร์ชันใหม่”** บนหน้า My day (หรือ ตั้งค่า › เวอร์ชันและอัปเดต › **ตรวจหาอัปเดต**)
3. กด **อัปเดตเลย** แอปจะ**สำรองข้อมูลให้อัตโนมัติ**ก่อน แล้วโหลดเวอร์ชันใหม่

**ทำไมเวอร์ชันเก่าไม่ยอมอัปเดต:** GitHub ให้เบราว์เซอร์เก็บไฟล์เดิมไว้ได้ 10 นาที และแอปที่ติดตั้งแล้วมักเปิดค้างอยู่เบื้องหลังจึงไม่โหลดใหม่ ตั้งแต่ v1.8 แอปโหลดไฟล์ใหม่จากเน็ตทุกครั้งและตรวจเวอร์ชันเองทุก 30 นาที/ทุกครั้งที่สลับกลับมาที่แอป

**ครั้งแรกที่ย้ายจากเวอร์ชันเก่ามา v1.8:** หลังอัปไฟล์แล้ว ให้ปิดแอปให้สนิท (ปัดทิ้งจากหน้าแอปล่าสุด) แล้วเปิดใหม่ 2 ครั้ง ครั้งต่อไปใช้ปุ่มอัปเดตได้เลย

**ข้อมูลไม่หายเวลาอัปเดต:** แอปบันทึกทุกครั้งที่แก้ สำรองอัตโนมัติวันละครั้งและก่อนอัปเดตทุกครั้ง (เก็บ 5 ชุดล่าสุด กู้คืนได้ที่ ตั้งค่า › เวอร์ชันและอัปเดต › สำรองอัตโนมัติ)

**ทุกครั้งที่ออกเวอร์ชันใหม่** ต้องแก้ 3 ที่ให้เลขตรงกัน: `APP_VERSION` ใน `index.html`, `version.json` และ `CACHE` ใน `sw.js` (ไฟล์ใน zip ตั้งให้แล้ว)

## แจ้งเตือนจริงแม้ปิดแอป (Push)

แอปทั่วไปที่เด้งได้แม้ปิดแอป มี “เซิร์ฟเวอร์” คอยปลุกมือถือตอนถึงเวลา เวอร์ชันนี้ใช้ Cloudflare แผนฟรีของคุณเองทำหน้าที่นั้น ตั้งครั้งเดียวประมาณ 10 นาที

1. สมัคร/เข้าสู่ระบบ [dash.cloudflare.com](https://dash.cloudflare.com) (ฟรี)
2. **Workers & Pages › Create › Create Worker** ตั้งชื่อ `secretary-push` › **Deploy**
3. กด **Edit code** ลบโค้ดเดิม วางโค้ดทั้งหมดจาก `push-worker.js` › **Deploy**
4. **Storage & Databases › KV › Create** ตั้งชื่อ `secretary-push`
5. กลับไปที่ Worker › **Settings › Bindings › Add › KV namespace** ชื่อตัวแปร (Variable name) **`KV`** เลือก `secretary-push` › Deploy
6. Worker › **Settings › Trigger Events (Triggers) › Add › Cron Triggers** ใส่ `* * * * *` (ทุก 1 นาที) › Add
7. เปิดลิงก์ Worker (เช่น `https://secretary-push.ชื่อ.workers.dev`) ในเบราว์เซอร์ ต้องขึ้นว่า “เซิร์ฟเวอร์แจ้งเตือนพร้อมใช้งาน”
8. ในแอป (ที่ติดตั้งจาก GitHub): **ตั้งค่า › การเตือนนัด › แจ้งเตือนจริงแม้ปิดแอป** วางลิงก์ › **เชื่อมต่อ** › อนุญาตการแจ้งเตือน › **ทดสอบเด้ง**

- เด้งตามที่ตั้งในแต่ละนัด: ก่อน 1 วัน / เช้าวันนัด 07:00 / ก่อน 2 ชม. ภายใน 1 นาทีของเวลาที่ตั้ง
- เพิ่ม/แก้/ลบนัดในแอป แล้วแอปส่งตารางเตือนไปเซิร์ฟเวอร์ให้เอง (ต้องต่อเน็ตตอนแก้)
- เซิร์ฟเวอร์เก็บแค่ชื่อนัด เวลา และสถานที่ ในบัญชี Cloudflare ของคุณเอง เครื่องแรกที่เชื่อมเป็น “เจ้าของ” เครื่องอื่นต้องใส่รหัสเจ้าของ
- ชื่อเมนูใน Cloudflare อาจต่างเล็กน้อยตามรุ่นหน้าเว็บ
- ถ้าตั้งค่าโหมดประหยัดแบตจนจำกัด Chrome การแจ้งเตือนอาจช้า: ตั้งค่ามือถือ › แอป › Chrome › แบตเตอรี่ › ไม่จำกัด

### 1) ครั้งแรก (ทำครั้งเดียว)

1. **ตั้งค่า › ข้อมูลในใบลงเวลา**: ชื่อ-นามสกุล, รหัสพนักงาน, ตำแหน่ง, แผนก (ใช้ในทุกฟอร์ม)
2. **ตั้งค่า › เวรและค่าเวร**: ตรวจอัตรา (8-8 = 2,000 บาท, STD = 200 บาท, STD เช้า = +100 บาท) และชั่วโมงที่นับ (เวรละ 8 ชม.; หยุด/STD = 0)
3. **ตั้งค่า › ชั่วโมงทำงานและการหักเงิน**: ใส่ “หักเงินชั่วโมงละ” (ชั่วโมงมาตรฐาน พ.ย. 2569 – ธ.ค. 2570 ใส่ไว้แล้ว)
4. **ตั้งค่า › อัตรา OT เรียกเคส**: ติ๊ก “ทำเคส Major / Minor” และ “ค่ายามวิกาล” ที่ใช้จริง › **บันทึกอัตรา OT**
5. **ใบเวร › ค่าเวร › เปลี่ยนโลโก้**: ใส่โลโก้โรงพยาบาล (ครอปจากรูปฟอร์มจริง)
6. **ตั้งค่า › ธีมและสี** (ล่างสุด): พื้นหลัง, สีพาสเทล, ฟอนต์, รูปช่องติ๊ก, ความใสของกรอบ

### 2) ต้นเดือน

1. **ตาราง › ลงตารางเวร**
   - **จากไฟล์**: เลือกไฟล์ตารางเวรของแผนก (.html / .xlsx) › ใส่รหัสพนักงาน › ตรวจรายการ › **ลงเวรที่เลือก**
   - **ลงทั้งเดือน**: แตะ 8-16 / STD / 8-8 / หยุด ได้วันละไม่เกิน 2 ช่อง (ช่องเหลืองที่เขียน 8-16 = แตะ 8-16 และ STD) › **บันทึก**
2. ตรวจปฏิทิน: จุด **ม่วง** 8-16 · **เหลือง** STD · **ส้ม** STD เช้า · **น้ำเงิน** 8-8 · **แดง** หยุด · ตัวเลขสีชมพู = วันหยุดบริษัท
   - วันหยุดที่มี STD 24 ชม.: แตะ **+STD เช้า** แอปติ๊ก STD ให้ด้วย รวม 300 บาท
3. **นัดหมาย › + นัดใหม่**: ใส่นัดของเดือน (ตั้งเตือนก่อน 1 วันให้อัตโนมัติ)
4. **ทีม › นำเข้าจากไฟล์ตารางเวร**: ใช้ไฟล์เดียวกับของแผนก ได้เวรเพื่อนทุกคน (ติ๊ก “อัปเดตเวรของฉันด้วย” ถ้าต้องการ) แตะชื่อเพื่อนเพื่อใส่เบอร์โทร

### 3) ทุกวัน

1. เปิด **My day** ดูเวร การ์ด **“วันนี้อยู่เวรกับ”** (เวรของเพื่อน + ปุ่มโทร ใช้ประกอบงาน Incharge) การ์ด “เดือนนี้” และสิ่งที่ห้ามลืม
   - **ขอแลกเวร:** ทีม › **สลับเวร** เลือกคนและวัน ดูผลก่อน คัดลอกข้อความ/โทร/SMS หาเพื่อน ตกลงแล้วกดบันทึก ตารางทั้งสองคนเปลี่ยนทันที (ถ้าเป็นเวรของคุณ ค่าเวรเปลี่ยนตาม) ย้อนกลับได้ใน “ประวัติการแลกเวร”
2. เลือก **หน้าที่วันนี้** (OR1 / OR2 / Sterile / Temp&Gas / เวชภัณฑ์ / Incharge / Stand by)
3. ติ๊ก **รูทีน** และกาง **Incharge ทำงาน** ติ๊กช่อง ทำ / ไม่ได้ทำ / N/A
4. **+ เคส**: ติ๊ก Major หรือ Minor ใส่เวลาเริ่ม-เลิก
   - ถูกเรียกนอกเวลา: ติ๊ก **เคส OT** (และ **ค่ายามวิกาล** ถ้าได้) แอปคิดเงินให้

## Prompt สร้างไอเดีย

My day › การ์ด **กิจกรรม · ไอเดียใหม่** › **💡 Prompt สร้างไอเดีย** (หรือ ตั้งค่า › Prompt ให้ AI › **💡 Prompt สร้างไอเดีย**) › **สร้าง Prompt** › **คัดลอก Prompt** › วางในแชตใหม่ของ Claude

Prompt (คำสั่ง) นี้ให้ AI:
1. สรุปวัตถุดิบของคุณ (ทักษะ เวลาว่างต่อสัปดาห์ ทุนจากรายรับรายจ่าย ความสนใจ)
2. ไอเดีย 10 ข้อ 3 กลุ่ม: ต่อยอดจากทักษะ/งาน · ต่อยอดจากไอเดียที่จดไว้ · ไอเดียใหม่นอกกรอบ
3. ตารางให้คะแนน 1–5 (เวลา ทุน ทักษะ รายได้ ความสนุก)
4. เลือก 3 ข้อ พร้อมความเสี่ยง การทดสอบใน 7 วัน (ทุน ≤500 บาท เวลา ≤3 ชม.) ก้าวแรก 30 นาที และวิธีวัดผล
5. แผนทดลอง 7 วันลงช่องเวลาว่างจริง (ไม่ใช้วันหลังเวร 24 ชม.)
6. ข้อความ 1 บรรทัดไว้จดกลับเข้าแอป (กด + ใน My day)

> ยิ่งจดไอเดียในแอปและเขียน “เกี่ยวกับฉัน” มาก AI ยิ่งคิดได้ตรงตัวคุณ

## Prompt สรุปตัวฉัน (ให้ AI วิเคราะห์)

ตั้งค่า › **Prompt ให้ AI** › **Prompt สรุปตัวฉัน**

1. เลือกเรื่องที่อยากให้ AI ช่วย: **ครบทุกด้าน / รู้จักตัวเองแบบไม่โกหก / หาเวลาทำไอเดียใหม่ / ขยายขีดจำกัด**
2. เลือกช่วงข้อมูล (30 วัน – ทั้งหมด) และรายละเอียดที่อยากใส่ (ชื่อนัด, แผนรายชั่วโมง, รายการเคส, ชื่อ)
3. เขียน **“เกี่ยวกับฉัน”** 10 ข้อสั้น ๆ (เป้าหมาย พลังงาน จุดแข็ง สิ่งที่ผัดวัน ความกลัว เงิน สุขภาพ คนสำคัญ ไอเดีย) แอปจำไว้ให้
4. กด **สร้าง Prompt** › **คัดลอก Prompt** › เปิดแชตใหม่ใน Claude แล้ววาง (หรือดาวน์โหลด .md / .json)

ข้อความจัดเป็น 13 หมวด: โปรไฟล์งาน · งานรายเดือน (ชั่วโมง ค่าเวร OT) · รูปแบบเวร · เคส · หน้าที่ · รูทีน · แผนรายชั่วโมง · นัด/สิ่งที่ต้องทำ · ไอเดีย · **เวลาว่างจริง 30 วันข้างหน้า** · **การเงิน (รายรับ รายจ่าย % เก็บเงิน)** · ทีม (จำนวนเท่านั้น) · เกี่ยวกับฉัน
พร้อมคำสั่งให้ AI วิเคราะห์แบบ**ตรงไปตรงมา อ้างตัวเลขจริง** บอกจุดแข็ง/จุดอ่อน หาไอเดียใหม่พร้อมก้าวแรก 30 นาที และออกแบบการทดลอง 2 สัปดาห์

> ทำเดือนละครั้งเพื่อดูความเปลี่ยนแปลง · ข้อมูลเพื่อน (ชื่อ เบอร์) ไม่ถูกใส่ · ตรวจก่อนส่งว่าไม่มีข้อมูลผู้ป่วย

## ความเป็นส่วนตัว

- โค้ดแอปบน GitHub เป็น Public แต่**ข้อมูลที่กรอกไม่อยู่ในโค้ด** เก็บเฉพาะในเบราว์เซอร์ของเครื่องที่ใช้
- ไม่มีชื่อ รหัส หรือข้อมูลส่วนตัวของใครฝังอยู่ในไฟล์ รวมถึงชื่อ เบอร์ และเวรของเพื่อนในหน้าทีม ซึ่งเก็บในเครื่องเท่านั้น (ขอความยินยอมเพื่อนก่อนเก็บเบอร์)
- แอปจะเตือนเมื่อพิมพ์คล้ายข้อมูลผู้ป่วย (HN, เลขเตียง) ไม่ควรเก็บข้อมูลผู้ป่วยในแอป
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลในแอปจะหาย จึงควรดาวน์โหลดไฟล์สำรองเป็นประจำ

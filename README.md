## ขึ้น GitHub Pages ทีละขั้น

ทำบนคอมพิวเตอร์จะง่ายที่สุด (บนมือถือก็ทำได้ผ่าน Chrome แบบ “เวอร์ชันเดสก์ท็อป”)

1. **สมัครบัญชี** ที่ [github.com](https://github.com) (ฟรี)
2. **สร้าง repository**: กด **+** มุมขวาบน › **New repository**
   - Repository name: `secretary` (ชื่อนี้จะเป็นท้ายลิงก์เว็บไซต์)
   - เลือก **Public** (GitHub Pages แบบฟรีต้องเป็น Public)
   - กด **Create repository**
3. **อัปโหลดไฟล์**: ในหน้า repository กด **uploading an existing file** (หรือ **Add file › Upload files**)
   - แตกไฟล์ zip ก่อน แล้วเลือก**ไฟล์ทั้ง 8 ไฟล์**อัปโหลดพร้อมกัน (ไม่มีโฟลเดอร์ย่อย อัปจากมือถือได้)
   - กด **Commit changes**
4. **เปิด GitHub Pages**: ไปที่ **Settings › Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** และโฟลเดอร์ **/ (root)** › กด **Save**
5. **รอ 1–3 นาที** แล้วรีเฟรชหน้า Settings › Pages จะขึ้นลิงก์แบบนี้
   `https://ชื่อผู้ใช้.github.io/secretary/`
6. เปิดลิงก์นั้น ใช้งานได้ทันที

> ⚠️ **ห้ามอัปไฟล์สำรอง (`secretary-backup-….json`) หรือไฟล์ Excel/PDF ที่ดาวน์โหลดจากแอปขึ้น GitHub** เพราะ repository เป็น Public ทุกคนเปิดดูได้

### เปลี่ยนชื่อลิงก์ภายหลัง
Settings › General › **Repository name** › พิมพ์ชื่อใหม่ (เช่น `secretary`) › **Rename** แล้วรอ 1–3 นาที ลิงก์จะเปลี่ยนเป็น `https://ชื่อผู้ใช้.github.io/ชื่อใหม่/` ข้อมูลในเครื่องยังอยู่ แต่ต้องลบไอคอนแอปเดิมแล้วติดตั้งใหม่จากลิงก์ใหม่

## ย้ายข้อมูลจากเวอร์ชัน claude.ai

ข้อมูลของแต่ละลิงก์แยกกัน ต้องย้ายเองครั้งเดียว

1. เปิดแอปบน **claude.ai** › **ตั้งค่า › สำรองข้อมูล › ดาวน์โหลดไฟล์สำรอง**
2. เปิดแอปบน **GitHub** › **ตั้งค่า › สำรองข้อมูล › นำเข้าไฟล์สำรอง** › เลือกไฟล์ › ยืนยัน
3. ใส่ **โลโก้ฟอร์ม** (ใบเวร › เปลี่ยนโลโก้) และ **รูปพื้นหลัง** (ถ้าใช้รูปของตัวเอง) ใหม่ เพราะรูปไม่ได้อยู่ในไฟล์สำรอง

ย้ายระหว่างมือถือกับคอมพิวเตอร์ก็ใช้วิธีเดียวกัน

## อัปเดตแอปเวอร์ชันใหม่

1. ใน repository กด **Add file › Upload files** แล้วอัปโหลด `index.html` ตัวใหม่ทับของเดิม › **Commit changes**
2. ถ้ามี `sw.js` ตัวใหม่ ให้อัปทับด้วย (ในไฟล์มีเลขเวอร์ชัน `secretary-v…` เปลี่ยนเลขทุกครั้งที่อัปเดต)
3. รอ 1–3 นาที แล้วเปิดแอป **2 ครั้ง** (ครั้งแรกโหลดของใหม่ ครั้งที่สองแสดงของใหม่)

**ข้อมูลเดิมไม่หาย** เพราะเก็บในเครื่อง ไม่ได้อยู่ในไฟล์บน GitHub (แต่แนะนำให้ดาวน์โหลดไฟล์สำรองก่อนอัปเดตทุกครั้ง)

## คู่มือการใช้งาน

### เมนูด้านล่าง

| เมนู | ทำอะไร |
|---|---|
| **My day** | เวรวันนี้, การ์ด “เดือนนี้” (ชั่วโมงขาด/เกิน, ค่าเวร+OT), หน้าที่วันนี้, รูทีน, Incharge checklist, เคส, แผนรายชั่วโมง, กิจกรรม/ไอเดีย |
| **นัดหมาย** | นัด, วันครบกำหนด, เรื่องรอติดตาม และการเตือน |
| **ตาราง** | ปฏิทินวัน/เดือน/ปี, ลงเวร, ค่าเวร, ชั่วโมงทำงาน |
| **ตั้งค่า** | ข้อมูลส่วนตัว, อัตราค่าเวร/OT, วันหยุดบริษัท, ส่งออก, สำรอง, ธีม |
| **แอป** | ไอคอนทางลัดไปแอปอื่น (เลือกไอคอนน่ารัก สี หรือใช้รูปของตัวเอง) |
| **ใบเวร** | ใบลงเวลา และฟอร์ม RLA/OT, ใบเบิกค่าเวร, ใบเบิกค่าเคส |
| **คู่มือ** | คู่มือแบบย่อในแอป |

### 1) ครั้งแรก (ทำครั้งเดียว)

1. **ตั้งค่า › ข้อมูลในใบลงเวลา**: ชื่อ-นามสกุล, รหัสพนักงาน, ตำแหน่ง, แผนก (ใช้ในทุกฟอร์ม)
2. **ตั้งค่า › เวรและค่าเวร**: ตรวจอัตรา (8-8 = 2,000 บาท, STD = 200 บาท) และชั่วโมงที่นับ (เวรละ 8 ชม.; หยุด/STD = 0)
3. **ตั้งค่า › ชั่วโมงทำงานและการหักเงิน**: ใส่ “หักเงินชั่วโมงละ” (ชั่วโมงมาตรฐาน พ.ย. 2569 – ธ.ค. 2570 ใส่ไว้แล้ว)
4. **ตั้งค่า › อัตรา OT เรียกเคส**: ติ๊ก “ทำเคส Major / Minor” และ “ค่ายามวิกาล” ที่ใช้จริง › **บันทึกอัตรา OT**
5. **ใบเวร › ค่าเวร › เปลี่ยนโลโก้**: ใส่โลโก้โรงพยาบาล (ครอปจากรูปฟอร์มจริง)
6. **ตั้งค่า › ธีมและสี** (ล่างสุด): พื้นหลัง, สีพาสเทล, ฟอนต์, รูปช่องติ๊ก, ความใสของกรอบ

### 2) ต้นเดือน

1. **ตาราง › ลงตารางเวร**
   - **จากไฟล์**: เลือกไฟล์ตารางเวรของแผนก (.html / .xlsx) › ใส่รหัสพนักงาน › ตรวจรายการ › **ลงเวรที่เลือก**
   - **ลงทั้งเดือน**: แตะ 8-16 / STD / 8-8 / หยุด ได้วันละไม่เกิน 2 ช่อง (ช่องเหลืองที่เขียน 8-16 = แตะ 8-16 และ STD) › **บันทึก**
2. ตรวจปฏิทิน: จุด **ม่วง** 8-16 · **เหลือง** STD · **น้ำเงิน** 8-8 · **แดง** หยุด · ตัวเลขสีชมพู = วันหยุดบริษัท
3. **นัดหมาย › + นัดใหม่**: ใส่นัดของเดือน (ตั้งเตือนก่อน 1 วันให้อัตโนมัติ)

### 3) ทุกวัน

1. เปิด **My day** ดูเวร การ์ด “เดือนนี้” และสิ่งที่ห้ามลืม
2. เลือก **หน้าที่วันนี้** (OR1 / OR2 / Sterile / Temp&Gas / เวชภัณฑ์ / Incharge / Stand by)
3. ติ๊ก **รูทีน** และกาง **Incharge ทำงาน** ติ๊กช่อง ทำ / ไม่ได้ทำ / N/A
4. **+ เคส**: ติ๊ก Major หรือ Minor ใส่เวลาเริ่ม-เลิก
   - ถูกเรียกนอกเวลา: ติ๊ก **เคส OT** (และ **ค่ายามวิกาล** ถ้าได้) แอปคิดเงินให้
   - อัตรา: Major 90 นาทีแรก 800 · Minor 60 นาทีแรก 400 · ทุก 60 นาทีถัดไป +400 · ค่ายามวิกาล 23:00–05:00 +400
5. จด **แผนรายชั่วโมง** และกด **+** มุมขวาล่างเพื่อจดกิจกรรม/ไอเดีย

### 4) สิ้นเดือน

1. **ใบเวร › ใบลงเวลา**: แตะวัน › **เพิ่มชั่วโมง** (ทำงานพิเศษ เช่น เตรียม HA = +6) / **ลดชั่วโมง** (ลารายชั่วโมง) / ติ๊ก **วันหยุดประจำปี** (+8 ชม. ไว้ดูเอง ไม่ลงใบเบิกและ RLA) · หรือที่หน้าตาราง กด **นับวันหยุดบริษัททั้งเดือน**
2. **ใบเวร › RLA/OT, ค่าเวร, ค่าเคส**: ข้อมูลเข้าฟอร์มให้เอง
   - แตะแถว (หรือ “แก้ทีละแถว”) เพื่อแก้ · แตะแถวว่างเพื่อเพิ่มแถว
   - แตะหัวกระดาษ ลายเซ็น หรือมุมล่าง เพื่อแก้ข้อความ
3. **บันทึกเป็น PDF (A4)** หรือ **Excel** แล้วพิมพ์ส่ง
4. **ส่งออก / แชร์**: Excel เดือนนี้ / ทั้งปี / ทั้งหมด หรือคัดลอกสรุปเป็นข้อความส่ง LINE
5. **ตั้งค่า › ดาวน์โหลดไฟล์สำรอง** เก็บไว้เดือนละครั้ง

## ความเป็นส่วนตัว

- โค้ดแอปบน GitHub เป็น Public แต่**ข้อมูลที่กรอกไม่อยู่ในโค้ด** เก็บเฉพาะในเบราว์เซอร์ของเครื่องที่ใช้
- ไม่มีชื่อ รหัส หรือข้อมูลส่วนตัวของใครฝังอยู่ในไฟล์
- แอปจะเตือนเมื่อพิมพ์คล้ายข้อมูลผู้ป่วย (HN, เลขเตียง) ไม่ควรเก็บข้อมูลผู้ป่วยในแอป
- ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลในแอปจะหาย จึงควรดาวน์โหลดไฟล์สำรองเป็นประจำ
